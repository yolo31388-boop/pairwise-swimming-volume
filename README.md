# pairwise-swimming-volume

角色跳进水里后直接沉底，浮力按整颗胶囊体积算，头露出水面时仍然按全身体积上浮；水面判定只用一个平面，波浪起伏时角色在水面上下反复切换游泳状态；水下相机没有近平面调整，贴着水面时整个屏幕被裁成黑色；角色从深水游向浅滩，水深小于胶囊半径时没有过渡，直接卡在河底；水流速度按固定向量施加，角色逆流时速度被叠加两次；水下视野没有雾和折射，远处物体像在空气中；冲刺游泳消耗体力，但体力耗尽后仍然保持游泳速度；出水动作没有检测池边高度，角色从水面直接弹上岸；多人游泳时位置同步只发水平坐标，浮潜状态在两端不一致；水下音效没有低通，听起来仍在岸上。gameplay/swimming_volume.py 是核心，tests/test_swimming_volume.py 15个红。要修的是：按浸没体积算浮力；按波高判定水面；水下近平面调整；浅水过渡；水流只施加一次；水下调色；体力影响速度；出水高度检测；同步潜水状态；水下低通。

## 运行

```bash
python -m pytest tests -q
```
